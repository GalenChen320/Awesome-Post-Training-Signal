大语言模型后训练主要消耗三类信号：**示范**（好的回答长什么样）、**偏好**（哪个回答更好）、**奖励/验证**（结果有多好）。本仓库专注于收录关于***如何获得这些信号***的工作（如任务、环境、验证器、评判器等）；不收录*如何消费这些信号*的工作（如训练算法等）。
